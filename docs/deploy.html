HomeGate

これはHomeGateのAdvanced / Developer installationです。一般利用者向けの標準導入はCloudflare OAuth Installerを使用します。

Deploy to Cloudflare

Deploy Buttonは公開リポジトリを使う開発者向けのフォールバックです。一般利用者にはGitHubアカウントを要求しないCloudflare OAuth Installerを案内してください。

デプロイ後

作成されたWorkerの /setup を開くと、DiscordのPublic KeyをCloudflare DashboardのSecretへ入力する手順が表示されます。SecretやTokenをHomeGateのフォーム、URL、HTML、ログへ送ることはありません。
